Drop your menu banner image here, e.g. `menu-banner.jpg`, and point
`MENU_IMAGE` in `.env` at it (path is relative to the project root,
e.g. `./assets/menu-banner.jpg`).

Supported formats: .jpg, .jpeg, .png
Size limit: 3MB (enforced in code — larger files are skipped with a
logged warning and the bot falls back to a text-only menu).

If MENU_IMAGE is left blank, .menu sends text only.
